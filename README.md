# LeafCare — Crop Disease Detection

A beginner-friendly BCA final-year project built with Python, Flask, TensorFlow/Keras, MobileNetV2, HTML, CSS, JavaScript, and SQLAlchemy. SQLite is used by default, with optional MySQL support.

> **Important:** Source code only is included. Download the image dataset and train the model before predictions are enabled. The app does not invent results when a model is missing.

## Features

- Upload one leaf photo or up to five crop/leaf photos per batch.
- Supports JPG, JPEG, PNG, and WEBP; maximum 8 MB per photo.
- Preview images, remove selected photos, and see a separate report for each image.
- Displays the predicted class, confidence, alternative classes, symptoms, and general prevention advice.
- Local prediction history (SQLite by default, optional MySQL).
- Uploaded photos are processed in memory and are not stored by the app.
- Responsive interface, image validation, and clear setup guidance.

## Requirements

Use **Python 3.11** (recommended; Python 3.10–3.12 is expected for the pinned TensorFlow 2.16.2). Internet is needed to install dependencies and download the dataset/pretrained model weights. Training time depends on your computer.

## Installation

1. Install Python 3.11 from https://www.python.org/downloads/ . On Windows, select **Add Python to PATH**.
2. Clone or download this repository and open the project folder in VS Code.
3. Create a virtual environment and install the packages.

### macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Windows

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Or run `install_mac.command` on macOS, or `install_windows.bat` on Windows, once.

## Dataset and training

1. Download a PlantVillage image dataset from https://www.kaggle.com/plantvillage/datasets (Kaggle login may be required).
2. Extract the images under `data/PlantVillage/`. Preserve the labelled class subfolders; the training script searches for directories containing images.
3. Activate `.venv` and train the model:

```bash
python train_model.py --data-dir data/PlantVillage --epochs 8
```

For a quick pipeline check, use `--epochs 2`. The first run downloads MobileNetV2's pretrained ImageNet weights. The script writes:

```text
model/crop_disease_model.keras
model/class_names.json
```

The dataset and trained model are not included in Git because the dataset is large and model weights are generated by training. Do not train from unlabelled images; each class must have its own folder.

## Run the app

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser. Choose **One leaf photo** or **Multiple crop photos**, select images, preview them, then analyse. Stop the server with `Ctrl+C` in the terminal. The model is trained on leaf images; close-up, well-lit leaf photos are recommended. Whole-plant/field pictures can yield unreliable predictions.

## Optional MySQL configuration

SQLite works without any additional configuration. To use MySQL, install and start MySQL Server, create a database and user, then set `DATABASE_URL` before starting the app. Example SQL:

```sql
CREATE DATABASE crop_disease_db CHARACTER SET utf8mb4;
CREATE USER 'cropuser'@'localhost' IDENTIFIED BY 'choose_a_password';
GRANT ALL PRIVILEGES ON crop_disease_db.* TO 'cropuser'@'localhost';
FLUSH PRIVILEGES;
```

macOS/Linux:

```bash
export DATABASE_URL='mysql+pymysql://cropuser:choose_a_password@127.0.0.1:3306/crop_disease_db'
python app.py
```

Windows PowerShell:

```powershell
$env:DATABASE_URL = 'mysql+pymysql://cropuser:choose_a_password@127.0.0.1:3306/crop_disease_db'
python app.py
```

Change the example password to your own and URL-encode reserved characters if needed. If `DATABASE_URL` is absent, the app stores history in `instance/crop_history.db`.

## Troubleshooting

- **`python` not found:** install Python 3.11 and reopen Terminal. On Windows, use `py -3.11`.
- **Missing Flask/TensorFlow:** activate `.venv`, then run `python -m pip install -r requirements.txt`.
- **TensorFlow installation fails:** check you're using 64-bit Python 3.10–3.12; Python 3.11 is recommended.
- **No dataset class folders found:** extract the ZIP and check each class-named folder contains image files.
- **Model not found:** verify both model files above exist and restart the Flask app after training.
- **Low confidence:** try a sharper close-up photo with one leaf in good light. Confidence is not a guarantee of correctness.
- **Port 5000 busy:** change the port at the bottom of `app.py` and open the matching local URL.

## Limitations and academic notes

This is an educational prototype, not a substitute for expert field diagnosis. Models trained on controlled PlantVillage-style images can perform worse on real farm photos. The classifier only selects among trained classes and may be wrong, even with high confidence. Guidance is general; confirm with an agricultural expert before applying pesticides or removing plants. For stronger evaluation, test on a separate real-world dataset and report per-class metrics and a confusion matrix.
