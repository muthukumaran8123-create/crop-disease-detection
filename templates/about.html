How LeafCare works

A practical demonstration of computer vision, machine learning, and a simple web interface for exploring crop-leaf disease classification.

◎

Project objective

Help students and growers explore how a leaf image can be classified into one of the disease or healthy classes represented in a training dataset. The system provides general educational guidance with each estimate.

⌘

Technology stack

PythonFlaskTensorFlow / KerasMobileNetV2HTML + CSS + JSSQLite (default)MySQL (optional)

SQLite works without a separate database server. To use MySQL, configure the DATABASE_URL environment variable as described in README.md.

↗

Methodology

Leaf image→Resize + augmentation→MobileNetV2→Class probabilities→Guidance

The training script uses transfer learning: a MobileNetV2 feature extractor pretrained on ImageNet is combined with a new classification layer and trained on labelled crop-leaf folders.

Train the model

The website code is installed, but a trained model must be created from a dataset before it can make predictions. Follow these steps from the project folder in Terminal or Command Prompt:

{% endif %}
  1. Download PlantVillageOpen the PlantVillage dataset page on Kaggle, download a dataset ZIP, and extract the images into data/PlantVillage/. Keep class subfolders and image filenames intact.
  2. Activate the environmentmacOS/Linux: source .venv/bin/activate
    Windows: .venv\Scripts\activate
  3. Train the classifierpython train_model.py --data-dir data/PlantVillage --epochs 8
    The script finds the class-folder directory automatically, makes an 80/20 validation split, and saves the model under model/.
  4. Run or refresh the websiteRun python app.py, then refresh http://127.0.0.1:5000. If the app was already running, restart it after training.

The first training run needs an internet connection to download MobileNetV2's pretrained weights. Training time depends on your computer and dataset size.

!

Important limitations

  • Predictions only cover the classes present in your training dataset.
  • PlantVillage-style images often have clean backgrounds; real field photos may be harder to classify.
  • Confidence is the model's score, not a guarantee that a diagnosis is correct.
  • Use the result as an educational aid, and confirm serious crop problems with an agricultural extension officer or qualified agronomist.
